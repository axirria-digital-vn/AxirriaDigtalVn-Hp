Perito for Jira – Documentation

Last updated: 22 October 2026

Perito writes test cases for a Jira issue using the issues linked to it and the tests you already have as context.

1. Install

  1. Open Perito for Jira on the Atlassian Marketplace and select "Get it now".
  2. Choose your Jira Cloud site. A site admin approves the permissions listed below.

Perito is free for teams of up to 10 users.

2. Permissions

PermissionWhy Perito needs it
read:jira-workRead the issue you run Perito on, its linked issues and its existing test cases
write:jira-workSave test cases to Jira as sub-tasks
read:jira-userIdentify the users who run Perito
storage:appStore test cases, run results and test-writing guidelines in Forge storage

Perito sends issue text to one external host: OpenAI's API (api.openai.com), to generate test cases.

3. Generate test cases

  1. Open a Jira issue and start Perito.
  2. Perito collects context: the issue, up to 10 directly linked issues, and the issue's existing test cases.
  3. Perito writes test cases. Every step has a concrete expected result, using the values written in the issue.
  4. New test cases are checked against existing tests to avoid duplicates.
  5. Test cases are saved to Jira as sub-tasks of the issue, and run results are recorded in Perito.

4. Test-writing guidelines

For each space, Perito keeps guidelines that help it write tests the way your team does. Open the "Test-writing guidelines" tab of the space to view, approve or turn off each guideline. Guidelines are used only for your own site and are never shared with other customers. To delete guidelines permanently, email contact@axirriadigital.com.

5. Data and privacy

  • Does data leave Atlassian? Yes. The text of the issue and its linked issues is sent to OpenAI's API to generate test cases.
  • Is my data used to train AI models? No. Perito does not train models, and OpenAI does not use API data to train its models. OpenAI may keep API data in abuse-monitoring logs for up to 30 days.
  • Where is data stored? In Atlassian Forge storage for your site. Perito does not use its own servers.

Details: Privacy Policy and Data Processing Addendum.

6. Uninstall

A site admin can uninstall Perito from Jira settings → Apps → Manage apps. Atlassian deletes the data Perito stored after the retention period set by the Forge platform. Test case sub-tasks that Perito wrote to Jira stay until you delete them.
