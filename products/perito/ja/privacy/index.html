Perito for Jira – プライバシーポリシー

最終更新日：2026年10月22日

本ポリシーは、Atlassian Jira Cloud 向けアプリ Perito for Jira（以下「Perito」）をご利用いただく際に、AXIRRIA DIGITAL VIETNAM LIMITED COMPANY（以下「当社」）がデータをどのように取り扱うかを説明するものです。

2. Perito がアクセスするデータ

テストケースを作成するため、Perito は、インストール時に許可された権限の範囲内でのみ、Atlassian の API を通じて次の情報を読み取ります。

  • Perito を実行した Jira 課題の内容（要約、説明、受け入れ条件など）
  • その課題に直接リンクされた課題（最大10件）。文脈として使用します
  • 課題の既存のテストケース。重複したテストを作成しないために使用します
  • Perito を実行したユーザーの Atlassian アカウント ID

Perito が Atlassian のパスワードや API トークンを求めたり、保存したりすることはありません。

3. Perito が Jira サイトに書き込むデータ

テストケースは、課題のサブタスクとして保存されます。

4. データの処理方法

Perito は Atlassian Forge 上で動作します。テストケースを作成するため、課題とそのリンク先の課題のテキストを、暗号化された通信で OpenAI の API（api.openai.com）に送信します。

  • OpenAI の API データポリシーにより、API を通じて送信されたデータが OpenAI のモデルの学習に使われることはありません。
  • OpenAI は、法令によりそれより長い保管が求められる場合を除き、API データを不正利用監視のログに最長30日間保管することがあります。
  • Perito は、処理のために送信するテキストの一時的なコピーを、リクエストが完了するまでの間だけ保持します。保持期間は最長1日です。
  • Perito は、課題の内容やプロンプトをログに書き込みません。

5. Perito が保存するデータ

Perito は、お客様のサイト用の Atlassian Forge ストレージ（Forge SQL および Forge キーバリューストレージ）にのみデータを保存します。独自のサーバーは使用しません。

  • テストケース、実行結果、確認が必要な点と、それに対する結論
  • AI リクエストの利用状況
  • テスト作成ガイドライン：Perito はスペースごとに、チームのルールに合ったテストを作成するためのガイドラインを保持します。ガイドラインは、スペースの「テスト作成ガイドライン」タブで確認、承認、または無効化できます。ガイドラインはお客様のサイトでのみ使用され、他のお客様と共有されることはなく、AI モデルの学習にも使用されません。

当社がお客様のデータを販売したり、広告に利用したりすることはありません。

6. 保管と削除

データは、Perito がインストールされている間、保管されます。Perito をアンインストールすると、Forge プラットフォームが定める保管期間の経過後に、Perito が保存したデータは Atlassian によって削除されます。Perito が Jira サイトに作成したテストケースのサブタスクは、お客様が削除するまで Jira に残ります。

テスト作成ガイドラインを含むデータの削除は、contact@axirriadigital.com へのメールでいつでもご依頼いただけます。2営業日以内にご返信します。

7. 個人データ

Perito は、Forge アプリ向けの Atlassian の個人データ報告の仕組みに対応しています。ユーザーが Atlassian アカウントを閉鎖した場合、当社はそのアカウントに関連する個人データを削除します。

8. セキュリティ

データは HTTPS で転送されます。本番データへのアクセスは、サポートの提供に必要な担当者に限り、かつお客様からのご依頼があった場合にのみ行います。

9. 変更

本ポリシーを変更する場合は、このページに掲載し、「最終更新日」を更新します。
