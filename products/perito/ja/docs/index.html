Perito for Jira – ドキュメント

最終更新日：2026年10月22日

Perito は、Jira の課題に対して、リンクされた課題と既存のテストを文脈として、テストケースを作成します。

1. インストール

  1. Atlassian Marketplace で Perito for Jira を開き、「Get it now」を選択します。
  2. Jira Cloud サイトを選択します。下記の権限は、サイト管理者が承認します。

10ユーザーまでのチームは無料でご利用いただけます。

2. 権限

権限Perito が必要とする理由
read:jira-workPerito を実行した課題、そのリンク先の課題、既存のテストケースを読み取るため
write:jira-workテストケースを Jira にサブタスクとして保存するため
read:jira-userPerito を実行したユーザーを識別するため
storage:appテストケース、実行結果、テスト作成ガイドラインを Forge ストレージに保存するため

Perito が課題のテキストを送信する外部ホストは、OpenAI の API（api.openai.com）の1つだけです。テストケースの作成に使用します。

3. テストケースの作成

  1. Jira の課題を開き、Perito を起動します。
  2. Perito が文脈を収集します。対象は、課題本体、直接リンクされた課題（最大10件）、課題の既存のテストケースです。
  3. Perito がテストケースを作成します。各ステップには、課題に書かれた値を使った具体的な期待結果が含まれます。
  4. 新しいテストケースは、重複を避けるため、既存のテストと照合されます。
  5. テストケースは課題のサブタスクとして Jira に保存され、実行結果は Perito に記録されます。

4. テスト作成ガイドライン

Perito はスペースごとに、チームのやり方に合わせてテストを作成するためのガイドラインを保持します。スペースの「テスト作成ガイドライン」タブを開くと、各ガイドラインを確認、承認、または無効化できます。ガイドラインはお客様のサイトでのみ使用され、他のお客様と共有されることはありません。ガイドラインを完全に削除するには、contact@axirriadigital.com までメールでご連絡ください。

5. データとプライバシー

  • データは Atlassian の外に送信されますか？　はい。テストケースを作成するため、課題とそのリンク先の課題のテキストを OpenAI の API に送信します。
  • データは AI モデルの学習に使われますか？　いいえ。Perito はモデルの学習を行わず、OpenAI も API データをモデルの学習に使用しません。OpenAI は API データを不正利用監視のログに最長30日間保管することがあります。
  • データはどこに保存されますか？　お客様のサイト用の Atlassian Forge ストレージに保存されます。Perito は独自のサーバーを使用しません。

詳しくは、プライバシーポリシーおよびデータ処理補遺をご覧ください。

6. アンインストール

サイト管理者は、Jira の設定 → アプリ → アプリを管理 から Perito をアンインストールできます。Forge プラットフォームが定める保管期間の経過後に、Perito が保存したデータは Atlassian によって削除されます。Perito が Jira に作成したテストケースのサブタスクは、お客様が削除するまで残ります。
