Perito for Jira – Privacy Policy

Last updated: [[ngày đưa lên web, dạng "21 October 2026"]]

This policy explains how Axirria Digital Vietnam Limited Company ("we", "us") handles data when you use Perito for Jira ("Perito"), an app for Atlassian Jira Cloud.

1. Who we are

Axirria Digital Vietnam Limited Company is the developer and provider of Perito.
Registered office: To dan pho Trung Son, Phuong Sam Son, Thanh Hoa, Vietnam.
Contact: contact@axirriadigital.com

2. Data Perito accesses

To write test cases, Perito reads the following through Atlassian's APIs, only within the permissions you grant at installation:

  • Content of the Jira issue you run Perito on: summary, description, acceptance criteria, comments, status and issue type
  • Related issues used as context: linked issues, issues in the same epic or parent, and issues found by keyword search in the same site, including bugs
  • Fields used to find related issues: links, epic or parent, components, labels and fix versions
  • Existing test cases, so that Perito can avoid writing duplicates
  • Atlassian account IDs of users who run Perito, to record who generated or reviewed a test case

Perito does not ask for or store your Atlassian password or API tokens.

3. Data Perito writes to your Jira site

  • When a requirement is unclear, Perito posts a comment on the issue that starts with "[Perito]" and lists numbered questions for your team.
  • [[Nơi Perito lưu test case trong Jira, ví dụ: "Test cases you approve are saved as sub-tasks of the issue." – Duy xác nhận]]

4. How data is processed

Perito runs on Atlassian Forge. To write test cases, the relevant issue text is sent over an encrypted connection to OpenRouter, Inc. (https://openrouter.ai/privacy), which routes the request to an AI model provider. We configure OpenRouter so that requests are sent only to providers with a zero data retention policy: your content is not stored by the model provider and is not used to train AI models. We do not enable prompt logging at OpenRouter.

5. Data Perito stores

  • Generated test cases and review results (kept, edited or dropped, and the reason given), stored in [[Forge Storage / Forge SQL – Duy xác nhận]] within your Atlassian site.
  • Project memory: notes and past answers that help Perito understand your project's business rules. You decide what Perito remembers, and you can view and delete memory at any time [[cách xem/xóa memory trong app]]. Memory is stored in [[nơi lưu memory – Duy xác nhận]] and is used only for your own site. It is never shared with other customers and is not used to train AI models.

We do not sell your data and do not use it for advertising.

6. Retention and deletion

Data is kept while Perito is installed. When you uninstall Perito, data stored by Perito is deleted according to Atlassian Forge data deletion rules. Comments and [[test case sub-tasks]] that Perito wrote to your Jira site remain in Jira until you delete them. You can ask us to delete data at any time by emailing contact@axirriadigital.com. We respond within 2 business days.

7. Personal data

Perito supports Atlassian's personal data reporting process for Forge apps. When a user closes their Atlassian account, we remove personal data linked to that account.

8. Security

Data is transferred over HTTPS. Access to production data is limited to staff who need it to provide support, and only on request from the customer.

9. Changes

We will post updates to this page and change the "Last updated" date.
