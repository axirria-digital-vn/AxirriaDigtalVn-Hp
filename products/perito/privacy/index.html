Perito for Jira – Privacy Policy

Last updated: 22 October 2026

This policy explains how Axirria Digital Vietnam Limited Company ("we", "us") handles data when you use Perito for Jira ("Perito"), an app for Atlassian Jira Cloud.

1. Who we are

Axirria Digital Vietnam Limited Company is the developer and provider of Perito.
Registered office: To dan pho Trung Son, Phuong Sam Son, Thanh Hoa, Vietnam.
Contact: contact@axirriadigital.com

2. Data Perito accesses

To write test cases, Perito reads the following through Atlassian's APIs, only within the permissions you grant at installation:

  • Content of the Jira issue you run Perito on, such as its summary, description and acceptance criteria
  • Up to 10 issues directly linked to that issue, used as context
  • Existing test cases of the issue, so that Perito can avoid writing duplicates
  • Atlassian account IDs of users who run Perito

Perito does not ask for or store your Atlassian password or API tokens.

3. Data Perito writes to your Jira site

Test cases are saved as sub-tasks of the issue.

4. How data is processed

Perito runs on Atlassian Forge. To write test cases, the text of the issue and its linked issues is sent over an encrypted connection to OpenAI's API (api.openai.com).

  • Under OpenAI's API data policy, data sent through the API is not used to train OpenAI's models.
  • OpenAI may keep API data in abuse-monitoring logs for up to 30 days, unless longer retention is required by law.
  • Perito keeps a temporary copy of the text sent for processing only until the request is complete, and for no longer than 1 day.
  • Perito does not write issue content or prompts to its logs.

5. Data Perito stores

Perito stores data only in Atlassian Forge storage (Forge SQL and Forge key-value storage) for your site. It does not use its own servers.

  • Test cases, run results, points that need clarification and the conclusions reached
  • Usage status of AI requests
  • Test-writing guidelines: for each space, Perito keeps guidelines that help it write tests that match your team's rules. Your team can view, approve or turn off these guidelines in the "Test-writing guidelines" tab of the space. Guidelines are used only for your own site, are never shared with other customers, and are not used to train AI models.

We do not sell your data and do not use it for advertising.

6. Retention and deletion

Data is kept while Perito is installed. When you uninstall Perito, Atlassian deletes the data Perito stored after the retention period set by the Forge platform. Test case sub-tasks that Perito wrote to your Jira site remain in Jira until you delete them.

You can ask us to delete data, including test-writing guidelines, at any time by emailing contact@axirriadigital.com. We respond within 2 business days.

7. Personal data

Perito supports Atlassian's personal data reporting process for Forge apps. When a user closes their Atlassian account, we remove personal data linked to that account.

8. Security

Data is transferred over HTTPS. Access to production data is limited to staff who need it to provide support, and only on request from the customer.

9. Changes

We will post updates to this page and change the "Last updated" date.
